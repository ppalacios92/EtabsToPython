# design.common

The shared foundation: contract, units, factors, and centralized code formulas.
See the guide: [The common layer](../guides/common.md).

The shear module includes one-way Table 22.5.5.1 helpers (`lambda_s`,
`vc_one_way`), §18.10 wall limits, and §22.6 two-way shear helpers
(`bo_rectangular`, `vc_two_way`, `vc_two_way_force`, and
`vc_two_way_max_with_stirrups`).
